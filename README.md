    # Case til forløb om Frontend udvikling på HTML, CSS og JavaScript på 2. semester

## Case: Studietypetest

Testen kortlægger, hvilken studietilgang den studerende overvejende bruger: **Dyb**, **Strategisk** eller **Overfladisk**.
Undersøgelsesdesignet er baseret på Entwistle NJ's forskning "The approaches and study skills inventory for students
(ASSIST)". Edinburgh: Centre for Research on Learning and Instruction, University of Edinburgh, 1997.

De studerende får 12 hverdagssituationer fra studielivet, og for hver situation vælger de det svar, der ligner dem
mest. Der er ingen rigtige eller forkerte svar. Testen besvares individuelt.
Når testen indsendes, sendes svarene som query-parametre (`q1`–`q12`) til en resultatside, som tæller op og viser
fordelingen mellem Dyb, Strategisk og Overfladisk.

I skal designe og implementere testen i HTML, CSS og JavaScript. I starter med at lave en HTML-side med spørgsmål og
svarmuligheder, dernæst styles siderne med CSS, og til sidst tilføjes JavaScript til at håndtere fremgang og vise
resultatet.

Da det er første gang I arbejder med webteknologier, og vi ikke bygger nogen backend, skal I ikke lave en database
til at gemme data undervejs.
